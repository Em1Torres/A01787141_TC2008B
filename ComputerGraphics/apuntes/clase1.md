Computer Graphics: A synthetic image (artificial) created by a computer model of real or virtual objects.

Modeling: create and represent the geometry of objects on the 3D world

Synthesis of images: generate 2D images based on the objects

Animation: the sequence of images

Image Processing: Analyze or reconstructing an object based on an image

Subjects: vectors, geomtry (polygons), shaders, lighting, perception of 3D

* Understand behaviour of light (lots of vector and maths for this behaviour)
* Use of vectors, normal vector (perpendicular vector from a suface or polygon so which way a polygon is facing).

**The graphics pipeline**

1. Vertex processor: camera and if moved translate the coordinates. 
2. Rasterizer: This pixel correspond to this part of the image
3. Fragment processor: give a color to each pixel
4. Result or Output merging: 2D image (3D positions into an image)

- This process for an image, its repeated to create animations
